# jetson-multimedia

Rust bindings to NVIDIA Jetson's multimedia libraries:

- **`NvBufSurface`**: hardware buffers backed by dmabufs, which V4L2 can capture straight into (`V4L2_MEMORY_DMABUF`)
- **`NvBufSurfTransform`**: colour conversion, scaling and cropping on the VIC
- **NVJPG**: hardware JPEG encoding through L4T's `libnvjpeg`

```rust
use jetson_multimedia::{ColorFormat, Filter, Jetson, JpegEncoder, Surface, Tag};

let jetson = Jetson::load()?;
let camera = Surface::new(&jetson, 1920, 1080, ColorFormat::Uyvy, Tag::Camera)?;
let yuv420 = Surface::new(&jetson, 1920, 1080, ColorFormat::Yuv420, Tag::None)?;
// queue camera.fd() to a V4L2 device as a DMABUF, dequeue a frame, then:
jetson.transform(&camera, &yuv420, Filter::Nearest)?;
let mut encoder = JpegEncoder::new(&jetson, 1920, 1080)?;
let jpeg: &[u8] = encoder.encode(&yuv420, 90)?;
```

## Supported releases

| JetPack | L4T | Bindings |
|---|---|---|
| 5 | R35 | `sys::l4t_r35_r36` |
| 6 | R36 | `sys::l4t_r35_r36` |
| 7 | R38 | `sys::l4t_r38` |

`Jetson::load()` reads `/etc/nv_tegra_release` and picks the matching bindings. JetPack 5 and 6 have the same layout
for every struct used here. JetPack 7 widened `NvBufSurface`, `NvBufSurfaceParams`, the transform rect and
`jpeg_compress_struct`, so it gets its own bindings. JetPack 4 used the older `nvbuf_utils` API and is not supported.

## How it works

- The libraries are opened at runtime with `libloading`. The crate builds on any 64-bit target, including CI machines
  and laptops, and `Jetson::load()` returns an error when it is not on a Jetson.
- `src/sys/` is generated by `generate_bindings.sh` from NVIDIA's public `nvidia-l4t-jetson-multimedia-api` debs. No
  Jetson is needed to regenerate it. Each struct carries bindgen's compile-time layout assertions, and a unit test
  checks that this crate's enums match every release's values.
- `libnvjpeg` is opened with `RTLD_LOCAL`. Its `jpeg_*` symbols use NVIDIA's extended `jpeg_compress_struct`, so they
  can't collide with a stock libjpeg linked into the same process.
- Set `JETSON_MULTIMEDIA_LIB_DIR` to load the libraries from a non-standard directory.

## Limitations

- Surfaces are pitch-linear with batch size 1.
- `JpegEncoder` takes YUV420 surfaces only. Convert with `Jetson::transform` first.
- A fatal libjpeg error still ends the process through libjpeg's default `error_exit`, as it would in C. Errors from
  `jpeg_start_compress` are caught and returned.

## Testing

```sh
cargo test                                   # anywhere: layouts, enum values, release parsing
cargo test --release                         # on a Jetson, also exercises the hardware
cargo run --release --example encode_bench   # on a Jetson: VIC convert + NVJPG encode timing
```
